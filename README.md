# 🔐 Password Generator

A simple Python project that generates secure random passwords.

## Features

- Generate strong passwords
- User chooses password length
- Uses letters, numbers, and symbols
- Beginner-friendly project

## Project Structure

```
password-generator/
│── main.py
│── README.md
│── requirements.txt
```

## Requirements

- Python 3.x

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Run the command:

```bash
python main.py
```

4. Enter the desired password length.

